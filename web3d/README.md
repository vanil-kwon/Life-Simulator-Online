# Life Simulator 3D — Mobile Web Prototype

Optimized first playable browser prototype for Xiaomi Redmi 14C (4 GB RAM).

- Three.js / WebGL, no Unity runtime.
- Third-person camera.
- Low-poly realistic city block, simple player and car placeholder.
- Touch joystick (left) and camera drag (right).
- Lightweight renderer: antialias off, pixel ratio capped at 1.35, no realtime shadows, fog and low-poly geometry.
- Initial needs HUD (health, energy, hunger).

Open in Chrome at the deployed `/3d/` route after the Pages workflow is merged/deployed.

This is a prototype, not a finished realistic game. Test on the target phone before raising resolution, adding shadows, NPC density or larger districts.
