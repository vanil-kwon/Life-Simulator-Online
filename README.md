# LIFE SIMULATOR — Pixel City

Первая офлайн-демоверсия пиксельного симулятора городской жизни. Проект подготовлен для разработки на Android через Termux и Acode.

## Что уже работает
- Главное меню с выбором OFFLINE / ONLINE (онлайн пока обозначен как будущая функция).
- Игровая карта Pixel City с дорогами, парками и зданиями.
- Управление персонажем с клавиатуры и экранным джойстиком.
- Взаимодействие с работой, NPC и зданиями.
- Простой автомобиль: можно сесть и управлять им.
- Работа приносит $150.
- Автосохранение и ручное сохранение в localStorage.
- PWA-заготовка для установки на главный экран и кэширования после первой загрузки.

## Запуск на Xiaomi Redmi

Открой Termux:

```bash
pkg update && pkg upgrade -y
pkg install nodejs-lts git -y
```

Распакуй архив в удобную папку, затем перейди в каталог проекта. Например:

```bash
cd ~/storage/shared/Life-Simulator-Online
npm install
npm run dev
```

Открой адрес, который покажет Vite (обычно `http://localhost:5173`), в браузере телефона.

## Сборка

```bash
npm run build
npm run preview
```

Для публикации на Cloudflare Pages используй:
- Build command: `npm run build`
- Build output directory: `dist`

## Офлайн-режим
Игра сохраняет профиль в localStorage браузера. После первой успешной загрузки опубликованной PWA service worker кэширует приложение. Для гарантированной работы офлайн открывай игру через установленное PWA-приложение или тот же браузер, в котором она уже была загружена.

## Важно про ONLINE
Кнопка ONLINE пока показывает сообщение о том, что сетевой режим будет добавлен позже. В архиве нет фиктивного мультиплеера, Supabase-ключей или небезопасной серверной логики. Следующим этапом можно добавить Supabase Auth и сервер комнат на Cloudflare Durable Objects.

## Структура
- `src/main.js` — меню, запуск Phaser и UI.
- `src/game.js` — игровая сцена, управление, машина, NPC, взаимодействия.
- `src/world.js` — процедурная карта города.
- `src/save.js` — локальные сохранения.
- `src/style.css` — интерфейс и мобильная адаптация.
- `public/` — PWA manifest, иконка и service worker.
